LyriSync
English

プライバシーポリシー

最終更新日：2026年10月4日 ／ 運営者：木村 匠（個人開発者）

LyriSync（以下「本アプリ」）は、利用者の個人情報を大切に扱います。本ポリシーは、本アプリがどの情報を、何のために、どこで扱うかを説明します。本アプリにはアカウント登録がなく、利用者の氏名・メールアドレス・電話番号などは取得しません。広告の表示や、行動の分析（アナリティクス）のためのツールも使用していません。

1. 取得・利用する情報

情報目的扱い
Apple Music で再生中の曲の情報（曲名・アーティスト名・ISRC・再生位置・曲の長さ）と、検索した曲曲を特定し、歌詞を再生に合わせて表示するため端末内で扱います。歌詞の取得に必要な曲名・アーティスト名・ISRC・曲の長さは、下記 2 のとおり歌詞サーバーに送ります。
マイクの音（「聞き取り」を使ったときだけ）周囲で流れている曲を特定するため本アプリは録音を保存せず、本アプリの運営者のサーバーにも送りません。曲の特定には Apple の ShazamKit を使い、音から作った音の特徴（シグネチャ）が Apple に送信されます（下記 3）。
音声認識の結果（歌詞の文字）カバー曲などを歌詞から探すため音声認識は端末内だけで行い、音声は端末の外に出ません。認識した歌詞の語句は、曲を探すために Apple Music のカタログ検索（MusicKit）に使われ、Apple に送信されます。
端末ごとの匿名 ID（ランダムに作る UUID）歌詞サーバーの過剰な呼び出しを防ぐため本アプリのインストールごとに端末内で作ります。氏名や Apple ID とは結びつきません。アプリを削除すると消えます。
設定・お気に入り・読み方の修正・利用回数・同期の調整値・同意の記録本アプリの機能の提供端末内にだけ保存します。運営者には送られません。
購入・購読の情報Premium 機能の提供Apple の App Store（StoreKit）が処理します。本アプリはクレジットカード情報などを取得しません。

2. 歌詞サーバーと歌詞提供元

本アプリは、同期歌詞を、運営者が管理する歌詞サーバー（Cloudflare, Inc. のサービス上で運用）から取得します。歌詞サーバーは、歌詞の権利者から許諾を受けた歌詞提供事業者のサービスから歌詞を取得します。

  • 歌詞サーバーに送る情報：曲名、アーティスト名、ISRC、曲の長さ、端末ごとの匿名 ID、および通信に付随する IP アドレス。
  • 歌詞サーバーは、匿名 ID を呼び出し回数の制限にだけ使います。歌詞提供事業者には、曲名・アーティスト名・ISRC・曲の長さを送り、匿名 ID は送りません。
  • 歌詞提供事業者との契約で求められる場合、歌詞を表示したときに、本アプリが提供事業者の計測用の URL を読み込むことがあります。このとき、通信の仕組み上、利用者の IP アドレスが提供事業者に届きます。
  • 歌詞の本文は、権利者・提供事業者の権利を守るため、端末に長期間は保存しません。

3. 外部サービス（Apple）

本アプリは Apple のサービス（MusicKit・ShazamKit・StoreKit・音声認識）を使います。これらで Apple が取得する情報は、Apple のプライバシーポリシー（https://www.apple.com/legal/privacy/jp/）に従って扱われます。

4. 利用者のコントロール

  • マイク・音声認識・Apple Music へのアクセスは、iOS の「設定」アプリでいつでも変更できます。許可しない場合、「聞き取り」など該当する機能は使えませんが、他の機能は使えます。
  • 本アプリを削除すると、端末内に保存した情報（設定・お気に入り・匿名 ID など）はすべて消えます。

5. 第三者への提供・共有

運営者は、上記 1〜3 の処理に必要な場合と、法令に基づく場合を除いて、利用者の情報を第三者に提供しません。情報を販売することはありません。

6. 保管期間と安全管理

運営者のサーバーは、曲名などの問い合わせ内容を、利用者を識別できる形で保存しません。通信は HTTPS で暗号化します。呼び出し回数の制限のために、匿名 ID を一時的に処理します。

7. 子どもの利用

本アプリは、お子様の個人情報を意図して取得しません。

8. 本ポリシーの変更

内容を変更するときは、このページを更新し、必要に応じてアプリ内でお知らせします。重要な変更があるときは、改めて同意をお願いすることがあります。
